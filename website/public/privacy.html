Privacy information for the WaveDock early-access preview. Updated October 28, 2026.

This website

The site is static and hosted on Cloudflare. It has no account system, advertising, custom analytics, or tracking cookies. Interactive demos run in your browser with sample data. Cloudflare processes network requests as the hosting provider. Following a GitHub or other external link takes you to that service’s privacy terms.

Local app data

Notes, tasks, layouts, shortcuts, and voice memos are stored locally. Microphone recording starts only when you press Record. Clipboard history is opt-in and stays in memory. The app does not upload these items to a WaveDock server.

Connected services

Enabled integrations contact their named services. Calendar uses macOS EventKit; music controls use macOS Automation. Weather sends the selected city to Open-Meteo; currency conversion sends the currency pair to Frankfurter. GitHub and API widgets request data directly from the chosen provider. API credentials are stored in macOS Keychain.

AI usage

Codex uses your existing local sign-in. The Claude Code bridge retains only allowlisted numeric usage and reset fields. Gemini imports retain only per-model numeric statistics. Prompts, response text, transcript paths, account passwords, and browser cookies are not retained by these bridges. Local usage snapshots can be cleared in the widgets. Connecting a CLI is optional and does not run AI prompts.

Permissions and limitations

Window control needs Accessibility; calendar, reminders, recording, and music features may request their corresponding macOS permissions. You can revoke permissions in System Settings. This preview is not notarized and has not undergone a production security audit.

Report a privacy issue or ask a question on GitHub. Do not include credentials, private recordings, or other sensitive data in a public issue.
